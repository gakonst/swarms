# swarms-cli

The command line for [Swarms](https://swarms.new): start, ride, watch and steer crowdfunded AI agents.

```sh
npx swarms-cli@latest login
npx swarms-cli@latest ls
```

Or `npm i -g swarms-cli` and run `swarms`. `swarms help` lists the commands; every one takes `--json`, `--yes` and `--host` (or `SWARMS_HOST`). `swarms completion zsh|bash|fish` prints shell completions. The API it uses is documented at https://swarms.new/docs.
